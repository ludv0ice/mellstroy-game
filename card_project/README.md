# Card Project: Проверка данных банковской карты

## Описание
Проект содержит класс `Card`, который реализует валидацию данных
банковской карты. В проекте предусмотрена проверка каждого поля
отдельно, а также общая проверка всех данных карты одновременно. Для
тестирования используется библиотека `pytest` с применением
параметризации и техники попарного тестирования.

## Правила валидации

- **Номер карты (`card_number`)**: строка, только цифры, ровно 16
символов (пробелы допускаются и удаляются перед проверкой), проверка
алгоритма Луна.
- **Имя владельца (`owner_name`)**: строка, ровно два слова, каждое слово
состоит только из латинских букв, длина каждого слова больше 1.
- **Срок действия (`expiry_date`)**: строка в формате `MM/yy` или
`MM/yyyy`. Месяц от 01 до 12. Дата должна быть валидной (месяц и год —
числа).
- **CVV-код (`cvv`)**: строка, ровно 3 цифры.

## Установка
### Создайте и активируйте виртуальное окружение:
```bash
python -m venv venv
venv\Scripts\activate
```
### Установите необходимые зависимости:
```bash
pip install -r requirements.txt
```
Содержимое requirements.txt:
```text
pytest>=8.4.2
pluggy>=1.6.0
pytest-cov>=7.1.0
coverage>=7.17.0
pygments>=2.20.0
```


## Запуск тестов
```bash
# 1. Запуск всех тестов в подробном режиме
python -m pytest -v

# 2. Запуск тестов из конкретного файла
pytest tests/test_card.py -v

# 3. Запуск тестов из конкретного класса
pytest tests/test_card.py::TestCard -v
```
## Проверка покрытия кода
```bash
python -m pytest --cov=app/utils --cov-report=html:coverage_re
```
